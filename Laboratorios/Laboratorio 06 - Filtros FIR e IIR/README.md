## **3) Ejercicio de Laboratorio para EEG** 
Se utilizaron 3 señales EEG obtenidas con BITalino en distintos estados: Ojos abiertos, realizando tarea cognitiva y realizando parpadeos
- **Filtro IIR:** Se utilizó un filtro Butterworth pasa banda de 0.5–30 Hz.
- **Filtro FIR:** Se diseñó un filtro FIR usando ventana Hann centrado en 12 Hz (banda alfa).
